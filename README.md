# 🏡 萌宠小镇 · 虚拟宠物养成（前后端分离版）

**前后端完全分离**的虚拟宠物养成小游戏：前端只负责渲染与交互，所有宠物状态、时间衰减、等级成长等逻辑都运行在**后端**，前端通过 `fetch('/api/pet')` 调用。后端存储走**适配层**，以后换 Redis / 腾讯云 CloudBase 只改一个文件。

## ✨ 功能
- 🐾 **开局领养**：在 🐱小猫 / 🐶小狗 / 🐰小兔子 三类中选择一只并取名（对齐 PRD §5.1 领养流程）
- 🧬 **物种差异化**：每种宠物性格与数值特质不同（如小狗饭量大、小兔子心情敏感），衰减速率由后端 `SPECIES` 目录统一配置
- 🩺 **四维养成**（对齐 PRD §5.2 日常养成）：饱食度 / 清洁度 / 心情值 / 健康度（0–100）
- 🍖 喂食 · 🛁 洗澡 · 🎾 玩耍(抚摸) · 😴 睡觉 · 💊 就医 · ✏️ 改名 · 🔄 放生重领
- 🤒 **医疗健康系统**（对齐 PRD §5.2.2）：疏于照料（饱食/清洁/心情任一过低）→ 健康下降 → 生病 🤒 → 需就医 💊 治疗；**兜底规则：低数值只触发负面状态，不会死亡/消失**
- ⏳ 状态随真实时间自然衰减（衰减在**后端**按时间戳回算，且按物种速率）
- 🏆 照顾次数累计 → 宠物亲密度等级；互动/任务累计经验 → **用户等级（Lv.）**
- 🏘️ **小镇四场景**（对齐 PRD §5.4）：🏥医院（就医/到访）、🏫学校（上课训练+经验）、🌳公园（散步+金币）、🛒商店（跳转商城）
- 🛒 **商城 + 货币**（对齐 PRD §5.5）：金币💰/钻石💎/代币🪙 三种货币；8 种商品（道具/服饰/家具），可购买、使用、装备
- 📋 **每日任务 + 成就**（对齐 PRD §5.6）：每日任务（喂食/玩耍/洗澡/公园）完成领取金币奖励；5 项成就自动解锁并发放钻石/代币
- 🔌 清晰的 REST 风格接口：`GET /api/pet`（含 species/scenes/shop/achievements 完整 catalog）、`POST /api/pet`

> 完整 PRD 见 `C:\Users\zhushuai2\WorkBuddy\2026-07-24-10-02-22\design\萌宠小镇_PRD原文.md`（V1.0 五大模块：领养/养成/装扮/小镇场景/商城）。当前 MVP 已实现：领养 + 日常养成 + 医疗 + 小镇四场景 + 商城货币 + 任务成就；装扮系统（宠物换装/房间自由拖拽）、异宠扩展、多宠切换为后续迭代。

## 🗂 目录结构（前后端分离）
```
mengpet-town/
├─ index.html          # 前端页面
├─ styles.css          # 样式
├─ app.js              # 视图层：只渲染 + 绑事件，调 lib/api.js
├─ lib/
│  └─ api.js           # 前端 API 客户端（本地仅存 petId，状态全在后端）
├─ api/
│  ├─ pet.js           # Vercel Serverless 入口（映射 /api/pet）
│  ├─ _petCore.js      # 业务核心：状态/衰减/互动（与框架无关，本地云端共用）
│  └─ _store.js        # 存储适配层（默认内存，可换 Redis/CloudBase）
├─ dev-server.js       # 本地一体化服务器（静态 + /api）
├─ package.json
└─ README.md
```

## 🚀 本地运行（无需 Vercel）
```bash
node dev-server.js
# 打开 http://localhost:3000
```

## 🌐 部署到 Vercel
1. 把本仓库推到 GitHub（部署需你本地 `git push`，本环境网络受限无法代推）。
2. 打开 [vercel.com](https://vercel.com) → GitHub 登录 → **Add New → Project** → 选本仓库 → **Deploy**。
3. 拿到 `https://项目名.vercel.app`，分享即可。Vercel 会自动把 `api/pet.js` 部署成 `/api/pet` 接口。

## 🔄 接真实持久化（多人共享同一只宠物）
当前后端用**内存存储**（Vercel 冷启动会清零，仅演示）。要持久化、要多人共享：
1. 打开 `api/_store.js`，把 `get/save` 换成 Upstash Redis 或腾讯云 CloudBase（接口不变）。
2. 前端、核心逻辑、Vercel 配置**都不用动**。
> 注意：现在每个浏览器靠本地 `petId` 区分宠物；要做"公共宠物/账号体系"，需在 `_petCore.js` 增加账号维度。
